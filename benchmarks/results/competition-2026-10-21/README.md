## Root causes corrected

- **rollback — lexical analysis/cleanup:** table inlining counted iterator uses
  but failed to substitute them. Resolve identifier nodes to lexical bindings,
  retain captured/mutated tables and dependency snapshots, and substitute exact
  references. Dead-local removal also respects reads, writes and `_` bindings.
- **matrix-scope — CFG:** backward loop-body traversal admitted FORGPREP entry
  edges into nested loops. Exclude those entry edges and use the FORGLOOP/FORNLOOP
  latch fallthrough as the continuation, preserving the outer body's effects.
- **codec — register ownership/naming:** a borrowed identifier was treated as
  its register's writable binding. Distinguish aliases from owned locals and
  avoid names that capture globals. Restore the split's register state before
  each alternative, discard branch-local temporaries at the join, and bind the
  join's phi values explicitly.
- **graph-walk — table materialization/terminal regions:** SETLIST read stale
  registers instead of pending child tables. Flush its element constructors,
  including fixed elements before an open return pack. Reject the `-1`
  post-dominator sentinel; reachability alone is insufficient to establish a
  join. Shared terminal regions are emitted independently in both alternatives.
- **branch-phis — SSA lexical ownership:** connected phi values in nested joins
  received unrelated branch-local names. Phi-to-phi edges now share a binding
  declared at the enclosing split. O1 remains correct. Value-if speculation
  retains the captured prelude value and restores the entry state per arm.

These fixes were derived from owned source, exact bytecode, disassembly, raw
reconstruction, final AST and VM traces. Competitor implementation code was not
copied. Prior changes to value-if comparisons, while-header effects and exact
numeric literals remain covered by the unchanged original benchmark.
