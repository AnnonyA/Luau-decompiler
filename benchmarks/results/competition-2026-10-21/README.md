## Three independent fixes

1. **Register reconstruction / expression selection** — `tryValueIf` built its
   comparison after speculative branch walks had overwritten its operands.
   In `ledger`, `i % 2 == 0` became `-i == 3`. Capture the complete comparison
   after its prelude and before either branch. Both ledger profiles now match.
2. **Loop emission** — effectful header statements were hoisted outside `while`.
   In `dispatch`, the repeat decrement ran once and the reconstructed loop then
   timed out. Keep materialized header statements inside the repeated body,
   before an explicit exit guard. Both dispatch profiles now match.
3. **AST cleanup** — approximate constant matching changed
   `3.141592653589` into `math.pi`, altering exact numeric results and introducing
   a global lookup. Retain numeric literals, even with the legacy `mathConstants`
   option. Both shadowed-constants profiles now match.

Four focused unit regressions failed before the fixes and pass afterward. The
old test expecting a new `math.pi` lookup was changed to require the exact literal.
The implementations were derived from our bytecode, AST and traces; no competitor
implementation source was copied.

## Remaining defects, ordered for follow-up

- **matrix-scope O0/O1 — CFG region follow / reconstruction:** the inner generic
  loop's follow points after the outer loop, skipping the `print("capture", ...)`
  call in the outer body. It is already missing in `annony.raw.luau`, before
  cleanup. Inspect `Structure.followOfLoop` and `Reconstructor.loopFollow` with
  nested generic loops; the observed inner follow is block 15 instead of the
  outer-body continuation at block 13.
- **rollback O0/O1 — cleanup/naming:** raw reconstruction passes all inputs;
  cleanup removes `local config2 = {2, value4, result, 1}` but retains
  `ipairs(config2)`. The final program references a nonexistent table. Track
  iterator uses through local elimination/inlining before removing a declaration.
- **codec O0/O1 — register lifetime/naming:** raw reconstruction overwrites the
  original byte string with the output length before comparing the strings,
  and creates `local print = 0`, capturing later calls to the global. Repair
  phi/register lifetime boundaries and reserve referenced global names.
- **graph-walk O0/O1 — pending table and branch reconstruction:** raw output turns
  nested adjacency tables into `{r2, 2, 3, 1}` and drops return paths from `visit`.
  Both defects precede cleanup; inspect nested SETLIST materialization and
  terminal-branch region handling separately.
- **branch-phis O0 — SSA binding placement and cleanup:** raw output declares
  branch values inside their arms while loop phis remain uninitialized; cleanup
  additionally merges distinct variables. Establish lexical ownership of each
  phi before name inference. O1 already matches; do not generalize that success.

Decoder/disassembly retains the relevant instructions in these probes; there is
no measured evidence that changing the printer or API options would fix them.
`rawDiagnostic` in the after JSON records the raw-stage execution comparison for
every remaining failure, rather than attributing all failures to cleanup.
