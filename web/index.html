What does source similarity measure?
Rosetta compares normalized token sequences: names, numeric values, and strings are normalized; comments and whitespace are ignored. The score reflects source structure, while a pass checks behavior. A 100% pass rate does not mean identical source.
These are reproducible results for Rosetta revision 80f3c13 and engine revision f9543bb, not a guarantee for every possible input.

Before you decompile.

Does my bytecode leave my device?
No. The browser downloads the static application and runs the engine in a local worker. Your bytecode is not sent to a decompilation service.

        
What files can I open?
Use Luau bytecode as a binary file or Base64 text. Official bytecode versions 3–9 are supported; versions 10–14 are experimental. The browser accepts up to 16 MiB. Encrypted or compressed wrappers need to be decoded first.

        
Will I get the exact original source?
Not always. Compilation can remove comments, original names, and source structure. LUVEX reconstructs readable code from the information that remains. Check Diagnostics for limitations and use the benchmark report to see measured fidelity.
